## Portfolio Projects

### 1. [Prompt Engineering Case Study](prompt-engineering-study.html)
Testing how different prompt structures affect output quality. Real tests with GPT-4 and Claude comparing zero-shot, few-shot, chain-of-thought, and role-based approaches.

**Key Finding:** Role + constraints prompting produced the highest quality output.

### 2. [AI Output Evaluation Framework](evaluation-framework.html)
A 7-dimension rubric for assessing language model responses:
- Factual accuracy
- Instruction-following
- Coherence & structure
- Naturalness & tone
- Audience appropriateness
- Completeness
- Safety & bias

### 3. [Swahili-English AI Evaluation](swahili-evaluation.html)
Quality assessment of AI-generated Swahili content. Demonstrates native language expertise and identifies common errors in translation, cultural appropriateness, and naturalness for the Kenyan market.

### 4. [Annotation Guidelines Template](annotation-guidelines.html)
Sample instructions for AI training annotation projects. Shows ability to write clear guidelines for data labeling teams.
